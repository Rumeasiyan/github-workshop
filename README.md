# GitHub workshop

For the office team.

You're going to plan the office trip to the beach together, on GitHub, and learn how teams work on GitHub along the way: from your first commit to the things professionals use every day.

- [MISSIONS.md](MISSIONS.md): what to do
- [CHEATSHEET.md](CHEATSHEET.md): the commands and buttons
- **Issues:** your missions, assigned to you
- **Discussions:** announcements and questions
- **Projects:** the scores

Team A works in [trip-team-a](https://github.com/Rumeasiyan/trip-team-a) and Team B in [trip-team-b](https://github.com/Rumeasiyan/trip-team-b).

**A few rules:**
- Use only these repos.
- Everything in them is made up, so don't add real data or passwords.
- Breaking things is fine. That's what they're for.
